# Setup

1. Open `https://github.com/mohitnivasjs/mohitnivasjs`.
2. Replace the repository's `README.md` with the new `README.md` in this package.
3. Ensure the workflow is located at `.github/workflows/snake.yml`.
4. Commit the changes.
5. Open **Actions** in the repository and run the snake workflow once if GitHub does not run it automatically.

The README uses your GitHub username `mohitnivasjs` and your LeetCode username `mohitnivasjs`.
