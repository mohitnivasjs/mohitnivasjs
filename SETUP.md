# Mohit Nivas JS — Profile README Setup

## 1. Create the profile repository

Create a **public** repository named exactly:

`mohitnivasjs`

GitHub displays the repository README at the top of your profile when the repository name matches your username and the repository is public.

## 2. Upload these files

Put `README.md` in the repository root and `.github/workflows/snake.yml` at the shown path.

## 3. Replace the LeetCode placeholder

In `README.md`, replace:

`YOUR_LEETCODE_USERNAME`

with your real LeetCode username.

## 4. Enable GitHub Actions

The snake workflow runs daily and can also be started manually from the Actions tab.

## 5. Pin your strongest repositories

Recommended starting pins:

- `AI-based-EDUCATIONAL-EQUITY-SYSTEM`
- `leetcode-tracker`
- `PROGRESS-YOUR-PROCESS`

As stronger projects are built, replace weaker pins so the profile always leads with your best work.
